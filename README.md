## 📖 About

Welcome to my personal portfolio repository!

This website is a place to showcase my projects, share a little about myself and document my journey as a developer.

Built using HTML and CSS, the portfolio is designed to provide a simple, accessible and visually appealing way to explore my work.

The website is continuously evolving as I develop new projects, learn new skills and experiment with different ideas.

## ✨ Features

- 🏠 **Homepage** – An introduction and central navigation.
- 👤 **About Me** – More information about me and my interests.
- 💻 **Projects** – A collection of my projects and work.
- 🎨 **Custom Design** – Custom HTML and CSS styling.
- 📱 **Responsive Layout** – Designed with different screen sizes in mind.
- 🗂️ **Multiple Pages** – Separate sections for easy navigation.
